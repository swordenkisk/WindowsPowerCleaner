# 🧹 Windows Power Cleaner v2.0

أداة شاملة ومجانية لتنظيف وتحسين أداء نظام Windows.

---

## ✨ المميزات

| الميزة | الوصف |
|--------|-------|
| 🗂️ ملفات مؤقتة | تنظيف TEMP و Windows Temp |
| 🌐 كاش المتصفحات | Chrome, Edge, Firefox, Brave, Opera |
| ⚡ Prefetch | تنظيف ملفات التحميل المسبق |
| 🔄 تحديثات Windows | حذف ملفات التحديث القديمة |
| 🗑️ سلة المحذوفات | تفريغ كامل |
| 🖼️ صور مصغرة | مسح Thumbnail Cache |
| 🌍 DNS Cache | مسح كاش DNS |
| 📁 ملفات كبيرة | مسح وإدارة الملفات الكبيرة |
| 🔍 وضع محاكاة | عرض ما سيتم حذفه قبل التنفيذ |
| 💾 نقطة استعادة | إنشاء تلقائي قبل التنظيف |
| 📊 تقارير | سجلات مفصلة بكل عملية |

## 🚀 تشغيل سريع

```bash
pip install -r requirements.txt
python main.py
```

## 📦 بناء ملف .exe

```bash
# الطريقة السهلة - تشغيل السكريبت
build.bat

# أو يدوياً
pip install pyinstaller
pyinstaller --onefile --windowed --name "WindowsPowerCleaner" main.py
```

## ⚙️ أوضاع التنظيف

| الوضع | ما يتم تنظيفه |
|-------|--------------|
| 🟢 آمن | ملفات مؤقتة + كاش متصفحات + ملفات حديثة + INet Cache + Thumbnails |
| 🟡 عميق | الآمن + Prefetch + كاش تحديثات Windows + DNS Cache |
| 🔴 شامل | العميق + سلة المحذوفات |

## ⚠️ تحذيرات

1. استخدم **وضع المحاكاة** أولاً لمعرفة ما سيتم حذفه
2. شغّل البرنامج **كمسؤول** للحصول على أفضل النتائج
3. فعّل **سلة المحذوفات** للتمكن من استرجاع الملفات
4. أنشئ **نقطة استعادة** قبل التنظيف العميق
